# 日线 MA7「上抛」扫描方案（C + B 兜底版）

> 实施日期：2026-11-03
> 适用标的：A 股日线（后复权）
> 实现：`ma7_system/ma7daily/upthrow.py` + `ma7_system/ma7_scan_close3.py`
> 配置：`ma7_system/config/ma7_close3.json`
> 与 v1（`ma7daily/signal.py` + `ma7_scan.py`）完全独立，互不影响。

---

## 0. 一句话

用 **MA7 的 5 日斜率**圈定「上抛段」，用 **价格连续 3 根站上 MA7** 确认信号：
**C（主）：段内首次收盘 > MA7 起连续 3 根**；
**B（兜底）：C 未出信号时，允许 1 日回踩后重新站上、连续 3 根**；
**D3 收盘确认 → D4 开盘执行**；D1、D2 给出候选。

---

## 1. 目标与定位

- **做什么**：盘后扫描，找出「MA7 由下行转上行、价格连续站上 MA7」的起点；
- **不做什么**：不预测收益、不评估买卖点、不在信号里叠加止盈止损；
- **输出**：今日确认（3/3）、候选（2/3、1/3）、段内状态（active），以及 CSV / meta；
- **使用节奏**：每个交易日收盘后跑一次，D3 收盘出的信号供 D4 开盘执行。

## 3. 规则定义

### 3.1 指标

```
MA7[t] = mean(close[t-6..t])                      # 7 日简单均线
s5[t]  = (MA7[t] / MA7[t-5])^(1/5) - 1            # 5 日斜率，单位 %/日
```

等价关系：`s5[t] > 0  ⇔  MA7[t] > MA7[t-5]`。

### 3.2 上抛段（段边界）

| 项目 | 规则 |
|---|---|
| 起点 | `s5` 由负转正，且**连续 2 个交易日 > 0**；起点记为第一根 |
| 持续 | `s5 > 0`；允许 **1 天**回踩（斜率 ≤0）不中断 |
| 终点 | `s5` **连续 2 个交易日 ≤ 0**；段终点记为最后一个 `s5 > 0` 的交易日 |
| 最短 | 2 天（1 天段不成立） |
| 进行中 | 数据末端仍 `s5 > 0` 的段，`seg_end_date` 为当前最后一根，标记进行中 |

### 3.3 信号（价格确认）

| 项目 | 规则 |
|---|---|
| C（主） | 段内**首次收盘 > MA7** 的那天为起点；从起点起连续 3 根收盘 > MA7 |
| B（兜底） | C 没出信号时，允许“前一天跌破、当天重新站上”；从重新站上日起连续 3 根收盘 > MA7；每段只取最早一次 |
| 互斥 | C 成功则不再找 B |
| D1 | 信号窗口起点；当日收盘 > MA7 → 候选 1/3 |
| D2 | D1、D2 收盘都 > MA7 → 候选 2/3 |
| **D3** | **三根收盘都 > MA7 → 信号确认 3/3** |
| 执行 | **D4 开盘**（确认日的下一个交易日） |
| 不设 | 斜率强度阈值（不要求 0.3%/日 等） |
| 跳过 | 段内价格从未站上 MA7 的斜率段，不构成上抛段 |

> 关键差别：C 把起点对齐到“价格首次站上 MA7”，B 再补“1 日回踩后重新站上”的情况；
> 因此 600188 的 2026-01-27 段会在 01-28 起算（信号 01-30），07-10 段会在 07-14 起算（信号 07-16）。

### 3.4 三种候选状态

| 状态 | 条件 | 含义 |
|---|---|---|
| 候选 1/3 | D1 收盘 > MA7 | 刚站上；段起点还要等 D2 确认（最新一根为“临时候选”） |
| 候选 2/3 | D1、D2 收盘都 > MA7 | 已站上 2 天；明天确认第 3 天 |
| **确认 3/3** | D1、D2、D3 收盘都 > MA7 | 信号成立；D4 开盘执行 |

## 4. 参数与配置

`config/ma7_close3.json`：

| 参数 | 默认 | 含义 |
|---|---:|---|
| `segment.slope_window` | 5 | 5 日斜率 |
| `segment.start_confirm` | 2 | 连续 2 天为正才确认段起点 |
| `segment.end_confirm` | 2 | 连续 2 天不为正才确认结束（允许 1 天回踩） |
| `signal.close_above_days` | 3 | 信号窗口连续 3 根收盘 > MA7 |
| `signal.fallback_reclaim` | true | C 未出信号时，启用 B 兜底（回踩后重新站上） |
| `signal.fallback_min_dip` | 1 | B 兜底要求的最少连续跌破天数（1 = 1 日回踩） |
| `scan.universe` | hs300 | 默认股票池 |
| `scan.recent` | 5 | 默认附带最近 N 日确认 |

MA7 窗口不重复配置，直接取 `config/ma7_daily.json` 的 `ma7.window`（默认 7）。

**常见调整**：

- 想更早确认：`close_above_days = 2`（D2 收盘就出信号，D3 开盘执行，但会放进更多假信号）；
- 想更严格：`close_above_days = 4`；
- 想减少回踩中断：`end_confirm = 3`（允许 2 天回踩，段会更长）；
- 想做“快线版”：`slope_window = 3`（信号更多、更碎，不建议单独使用）。

## 5. 每日工作流

### 5.1 收盘后运行

```powershell
cd F:\ai_multi_level_resonance\ma7_system

# 沪深300
python ma7_scan_close3.py --universe hs300

# 全市场
python ma7_scan_close3.py --universe all --recent 5

# 单票
python ma7_scan_close3.py --codes 000400 --date 2026-11-02 --recent 10
```

### 5.2 看三张表

1. **今日确认 3/3**：`start`=D1，`date`=D3（确认日），`entry`=D4 开盘；D4 开盘执行；
2. **候选 2/3**：已站上 2 天，明天收盘决定是否确认；
3. **候选 1/3**：今天刚站上，明天继续站上才进入 2/3。

> 最新交易日确认的信号，`entry` 为下一交易日（数据中尚无），CSV 里为 NaT，这是正常的。

### 5.3 段内状态

`段内: N` 是当日仍处于上抛段内的股票数（含尚未确认 3/3 的段），用于跟踪和观察，不是买入清单。

## 6. 输出

### 6.1 CSV

`output/ma7_scan_close3_YYYYMMDD.csv`，列：

| 列 | 含义 |
|---|---|
| `bucket` | `confirmed` / `candidate2` / `candidate1` |
| `stock_code` / `stock_name` | 代码 / 名称 |
| `seg_start_date` | 段起点 D1 |
| `trade_date` | 扫描日（确认行是 D3，候选行是当天） |
| `close_price` / `ma7` / `s5` | 当日收盘 / MA7 / 5 日斜率 |
| `seg_day` | 段内第几天（1/2/3…） |
| `confirm_date` | 确认日（仅 confirmed 行） |
| `entry_date` | 执行日（仅 confirmed 行，D4） |
| `seg_end_date` | 段终点（进行中为最后一根；历史回放时会包含未来数据，仅作参考） |

### 6.2 Meta

同名 `.meta.json`：规则、配置、数据区间、股票池 update_date、各 bucket 计数、生成时间。

## 8. 与 v1 的区别

| 项目 | v1（`ma7_scan.py`） | v2（`ma7_scan_close3.py`） |
|---|---|---|
| 段定义 | MA7 单日上拐 + K 线质量 + 次日确认 | MA7 5 日斜率 > 0，2 日确认起止，允许 1 日回踩 |
| 信号 | 收盘 > MA7、实体阳线、收盘位置、量能、更高低点 | C：段内首次站上日起连续 3 根收盘 > MA7；B：C 未出时允许 1 日回踩后重新站上、连续 3 根 |
| 确认 | 下一交易日 MA7 继续上行 | 第 3 根收盘 |
| 执行 | 确认日次日开盘 | 第 4 根开盘 |
| 密度（2026） | 000400 10 个起点 | 000400 5 个 / 600188 7 个 |
| 斜率强度 | 无（可选） | 无（段方向由 s5>0 保证） |
| 输出 | 今日确认 / 上抛中 / recent | 确认 3/3 / 候选 2/3 / 候选 1/3 / 段内 |

C+B 把“价格站稳”作为确认，同时用 B 兜住“1 日回踩后重新站上”的段；信号比 v1 少，但更贴近实际走势。

## 10. 边界与注意事项

1. **最新一根**：`entry_date` 为 NaT（下一交易日不在数据里），CSV 里正常显示为空；
2. **历史回放**：`--date` 回放时，`seg_end_date` 是真实段终点（含未来信息），只作参考，不要用于当时决策；
3. **节假日**：3 根 K 线按交易日算，国庆/春节会跨假期（如 09-29 的第 3 根是 10-08）；
4. **停牌**：`trade_date` 是该股的下一根 K 线，长期停牌会让确认日跨很久；v2 未单独过滤，必要时加 `max_gap`；
5. **数据新鲜度**：同步失败会告警并使用本地缓存；若缓存停在旧日期，扫描结果也是旧日期，运行前看 `交易日`；
6. **幸存者偏差**：`hs300` 是当前成分快照（update_date=2026-08-10），回测历史会有偏差；
7. **不构成交易建议**：本扫描只输出状态，不含仓位、止盈止损、成本、涨跌停过滤。
