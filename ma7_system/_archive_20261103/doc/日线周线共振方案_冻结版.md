# 日线 + 周线共振方案（冻结版）

> 冻结日期：2026-11-03
> 状态：**冻结**，规则不再修改；后续只更新数据、按此口径运行。
> 替代：v1 日线（`ma7_scan.py`）、日线单腿 v2（`ma7_scan_close3.py`）不再作为标准；
> 周线/月线旧扫描保留仅作参考。

## 1. 周线上抛区间

| 项目 | 规则 |
|---|---|
| 指标 | 周线 MA7 = 7 周 SMA；`s5w = (MA7w[t]/MA7w[t-5])^(1/5)-1` |
| 起点 | 周线斜率段内（`s5w>0` 连续 2 周，允许 1 周回踩，连续 2 周 ≤0 结束），**首次收盘 > 周线 MA7** 的那一周 |
| 终点 | **连续 3 周收盘 < 周线 MA7**，第 3 周为结束确认周 |
| 区间 | 起点 ~ 结束确认周 |

- 同一周线斜率段内，若价格中途出现 3 周跌破后重新站上，会切分成两个区间（不合并）。

## 2. 日线信号

| 项目 | 规则 |
|---|---|
| 指标 | 日线 MA7 = 7 日 SMA；`s5 = (MA7[t]/MA7[t-5])^(1/5)-1` |
| 日线段 | `s5>0` 连续 2 天起；允许 1 天回踩；连续 2 天 ≤0 结束 |
| C（首次站上） | 段内首次收盘 > MA7，且当天起**连续 3 天收盘 > MA7** |
| B（回踩再站上） | 前一日收盘 < MA7，当日重新站上，且当天起连续 3 天收盘 > MA7 |
| 多信号 | **每段内 C 一次 + 每次 B 回踩都给一次信号**（方案 3） |
| 确认 | 3 天窗口的第 3 天收盘 |
| 开仓 | 确认日的**下一个交易日开盘** |

## 3. 共振条件

日线信号的**确认日**必须落在某个周线上抛区间内：

```
weekly_start <= 日线确认日 <= weekly_end
```

- 日线信号在周线区间之前或之后 → 不开仓；
- 日线信号在周线区间内 → 开仓。

## 4. 平仓（日线）

**连续 3 个交易日收盘 < 日线 MA7 → 次日开盘平仓。**

- 不设固定持有天数；
- 数据末端未触发则按最后一根收盘计（未平仓）。

## 5. 参数

| 参数 | 值 |
|---|---:|
| 日线/周线 MA7 窗口 | 7 |
| 斜率窗口 | 5 |
| 段起点确认 | 2 |
| 段终点确认 | 2（允许 1 天回踩） |
| 信号确认根数 | 3 |
| 周线结束跌破周数 | 3 |
| 交易成本（回测） | 0.2% 双边 |

原文未写、实现时补的三个口径（可用参数关闭）：

- **单仓**：同一票持仓中，新的共振信号不执行（`--position-mode add` 可关闭）；
  这与参考输出 `600188_opt3_exit3.csv` 的 46 笔一致（不限仓是 59 笔）。
- **进行中区间**：数据末端尚未跌破的区间按「进行中」处理并显示。
- **周线只用已收盘周**（`period_end <= 当日`）；`--strict-week` 进一步要求
  斜率段被下一周确认（严格因果，会挡掉「区间起点=段起点」当天的信号）。

日期固定为三个，互不混用：

| 名称 | 定义 | CSV 列 | 000400（2026-11-02 收盘） |
|---|---|---|---|
| 信号日 D1 | 窗口起点：首次站上 / 回踩后重新站上 MA7 | `signal_date` | 2026-11-02 |
| 确认日 D3 | 窗口第 3 根收盘（signal=True 那天） | `confirm` | 待 11-04 收盘 |
| 开仓日 D4 | 确认日的下一个交易日开盘 | `entry` | 待 11-05 开盘 |

> v1（`ma7_scan.py`）的「信号日=首根上拐日、确认日=下一交易日」是两日节奏；
> 本方案是三日窗口，确认日改为 D3，但**信号日仍然是 D1**，不会没有。
