# 日线 MA7「上抛」规则（独立策略）

> 本规则与既有的日/周/月 MACD 共振管线**完全独立**：
> 不修改 `mlr/resonance.py`、`mlr/backtest.py`、`scan.py`、`backtest.py`、
> `config/resonance.json`。实现位于 `ma7_system/ma7daily/`，参数唯一来源
> `ma7_system/config/ma7_daily.json`，入口
> `ma7_system/ma7_scan.py` / `ma7_backtest.py` / `ma7_tf_scan.py` /
> `ma7_tf.py`，输出在 `ma7_system/output/`。

## 1. 图例拆解（600985 淮北矿业，2026）

两个红框是同一套结构在不同位置的重复：

### 方框 1（7 月低点 → 8 月中）

1. **下跌末端**：MA7 陡峭下行，K 线连续收在 MA7 下方；
2. **探底走平**：最低 19.21 附近出现长下影 / 小实体，随后 3~5 根小阴小阳，
   **MA7 由下行转为走平**；
3. **收复 MA7**：一根实体较大的阳线收盘站上 MA7（放量），MA7 开始上翘；
4. **沿 MA7 上抛**：阳线为主、阶梯抬高；阴线多为小实体、缩量，最低价回踩
   MA7（±1%）后收盘收回，1~2 日恢复；
5. **加速段**：MA7 斜率递增，收盘对 MA7 的正偏离扩大；
6. **终结**：放量长阴 / 连续阴线跌破 MA7，MA7 走平下弯，反弹受 MA7 压制。

### 方框 2（10 月）

与方框 1 同构、尺度更小：下跌 → MA7 走平 → 阳线收复 → 小阴回踩不破 →
MA7 上翘 → 沿线上行（截图右端仍在进行）。

## 2. K 线与 MA7 的规律

| # | 规律 | 具体表现 |
|---|---|---|
| 1 | MA7 是上抛的生命线 | 上抛段 K 线贴着 MA7 上行，MA7 由压力变支撑；收盘绝大多数时间在 MA7 上方 |
| 2 | 拐点先于突破 | 起点不是最低点，而是 MA7 由下行转为上行的**第一根上拐**；价格突破只是表象 |
| 3 | 上拐要确认 | 第一根上拐后，**下一交易日 MA7 继续上行**才算有效；若次日 MA7 又转跌，前一日不成立 |
| 4 | 更高低点 | 起点日最低价高于前一日最低价，代表抛压衰竭 |
| 5 | 回踩有容忍度 | 阴线小实体缩量，低点可触及/瞬时下破 MA7，但收盘收回；连续 2 根收盘跌破才算破坏 |
| 6 | 终结有信号 | 放量长阴/连续阴线跌破 MA7，MA7 走平下弯；反弹不过 MA7 确认转弱 |

## 3. 可计算化规则

```
MA7[t]       = mean(close[t-6..t])
ma_up[t]     = MA7[t] > MA7[t-1]
higher_low[t]= low[t] > low[t-1]
raw[t]       = close[t] > MA7[t]
               AND ma_up[t]
               AND higher_low[t]
               AND K线质量（实体阳线/收盘位置/量能）
               AND 突破新鲜度 fresh[t] <= fresh_cross_days
               [可选] AND 级别过滤：近 20 日 MA7 自局部高点回撤 >= 1.25%
confirm[t]   = raw[t] AND MA7[t+1] > MA7[t]
signal_date  = t          # 空仓状态下首次满足的当日，例如 7/14、10/9
confirm_date = t+1        # 次日确认，例如 7/15、10/12

fresh[t]     = MA7 连续上行已持续的天数（fresh_mode=since_turn，默认）
             | 收盘连续站上 MA7 的天数（fresh_mode=above_run，旧口径）

up_state = signal_date 后保持，直到：
           连续 exit_below_days 日 close < MA7
           或 连续 exit_slope_days 日 slope < -0.05%/日
```

> 关键点：信号日是 **MA7 上拐且空仓状态下首次满足全部条件** 的当日，
> 不是价格突破日，也不是确认日。7/14 的信号在 7/15 得到确认；
> 10/9 的信号在 10/12 得到确认。9/30 虽然 MA7 当日上拐，但低点低于
> 9/29，且 10/8 MA7 又转跌，因此不成立；10/26 只是 10/9 这一段的延续。
> 对 000400，MA7 在 9/28 已上拐，但 9/28 低点更低；9/29 首次满足
> “更高低点 + 收盘站上 MA7”，所以信号日是 9/29。
>
> `fresh_mode` 的差别：旧口径 `above_run` 在收盘跌破 MA7 的当天就清零，
> 于是一段上涨里每次回踩都会重生一个起点（段数膨胀）；默认的
> `since_turn` 看的是「MA7 这段连续上行已经走了几天」，回踩不会重置，
> 只保留趋势刚起步时的 1~5 根。

### 默认参数（`config/ma7_daily.json`）

| 参数 | 默认 | 含义 |
|---|---|---|
| `ma7.window` | 7 | MA7（图上的白线） |
| `ma7.k` | 3 | 3 日复利斜率（仅展示/可选过滤） |
| `ma7.use_slope_filter` | false | 是否额外要求 3 日斜率 ≥ `theta` |
| `ma7.theta` | -0.0005 | 仅 `use_slope_filter=true` 时生效 |
| `ma7.require_higher_low` | true | 起点日低点高于前一日 |
| `ma7.confirm_next_up` | true | 下一交易日 MA7 继续上行才确认 |
| `ma7.fresh_cross_days` | 5 | 只做刚收复 MA7 的 1~5 日内 |
| `ma7.fresh_mode` | `since_turn` | `since_turn`=MA7 连续上行天数；`above_run`=收盘连续站上 MA7 天数（旧口径） |
| `ma7.bullish_only` | true | 当日收盘 > 开盘（实体阳线） |
| `ma7.min_body_pct` | 0.3 | 实体涨幅 ≥ 0.3% |
| `ma7.min_close_pos` | 0.6 | 收盘位于当日振幅上方 40% |
| `ma7.min_vol_ratio` | 0.8 | 成交量 ≥ 前 5 日均量的 0.8 倍 |
| `ma7.reset_drawdown_pct` | null | 级别过滤：入场前 MA7 回撤 ≥ X%（null=关，上限 1.5%） |
| `ma7.reset_dd_lookback` | 20 | 级别过滤的回看窗口（交易日） |
| `state.exit_below_days` | 2 | 连续 2 日收盘 < MA7 → 上抛结束 |
| `state.exit_slope_days` | 2 | 连续 2 日斜率 < -0.05%/日 → 上抛结束 |
| `state.exit_slope_threshold` | -0.0005 | 走平/轻微下行不算破坏 |
| `state.cooldown_days` | 0 | 退出后 N 日内不再入场 |
| `backtest.exit_mode` | `state` | `state`=跌破 MA7 连续 2 日离场；`fixed`=固定持有期（旧口径） |
| `backtest.state_horizons` | 60/120/250 | state 模式下的最长持有上限 |

K 线质量默认较宽，是为了容纳 7/14（量比 0.84）和 10/9（实体仅 0.39%）
这类“小实体但结构成立”的起点；如要更严格可调高
`min_body_pct` / `min_vol_ratio`。注意 10/9 的实体只有 0.39%、量比不足 0.9，
所以 `min_body_pct` / `min_vol_ratio` 不能再往上加，否则基准样本会丢。

### 回测退出口径

* `exit_mode=state`（默认）：ABM 事件驱动，`close < MA(7) * (1-eps)` 连续
  `breakdown_days`（默认 2）日即离场，与扫描的 `up`/`exit_flag` 同构；
  `state_horizons=[60,120,250]` 只是「最长持有上限」，用于处理数据末端与
  极端长段（实测段长中位 7 日、p90 16 日、最长 67 日）。
* `exit_mode=fixed`：旧口径，固定持有期（`horizons`），保留用于对照。
* 两处已知小差异：ABM 的 breakdown 用「前一根 MA7」与当日收盘比较，并在
  第 2 根跌破日的**收盘**成交；`ma7daily` 的状态退出在**次日开盘**执行。
* 扫描里的「斜率退出」（连续 2 日 slope < -0.05%/日）没有在回测中建模，
  只用于状态展示——要专门验证它，请用 `ma7_tf.py` 的 bar 级回测。

### 降噪预设 `strict`

默认口径信号很密（沪深300、2020 起：18,676 个起点，约 9.2 个/票/年，
35% 的股票日处于“上抛中”）。`--preset strict` 叠加三件事：

| 项 | 值 | 作用 |
|---|---|---|
| `ma7.fresh_cross_days` | 3 | 只做 MA7 上行段最初 3 日内 |
| `ma7.reset_drawdown_pct` | 1.25 | 入场前 20 日 MA7 自局部高点回撤 ≥1.25%（区分真“挖坑”与小回踩） |
| `state.cooldown_days` | 10 | 退出后 10 个交易日内不再入场 |

实测：起点 18,676 → **10,007**（每票每年 9.2 → 5.0），000858
2026-07-14 / 10-09、000400 2026-09-29、600985 2026-07-14 全部保留。
`reset_drawdown_pct` 有硬上限 **1.5%**（10/9 的 20 日 MA7 回撤仅 1.54%），
`settings.validate_config` 会在超过时给出提示。

> 想把密度进一步压到 1~3 个/票/年，靠参数微调做不到（`reset_lookback`
> 斜率口径、`cooldown` 20 日等组合要么只降到 4~5 个，要么直接滤掉 10/9）；
> 需要改判据本身（例如只取“下跌 ≥X% 后的首次上拐”并放弃部分小级别起点）。

## 4. 用法

```powershell
# 盘后扫描：当日确认信号 + 最近 5 个交易日的起点
python ma7_scan.py --recent 5
python ma7_scan.py --recent 5 --preset strict      # 降噪口径

# 全部上抛中 / 指定日期 / 其他股票池
python ma7_scan.py --all-state
python ma7_scan.py --date 2026-10-23
python ma7_scan.py --universe all

# 回测（默认沪深300、state 退出、open_open、成本 0.2%）
python ma7_backtest.py
python ma7_backtest.py --horizons 60,120,250
python ma7_backtest.py --exit-mode fixed --horizons 20,30,40,60   # 旧口径对照
python ma7_backtest.py --universe coal
python ma7_backtest.py --codes 000858
```

产物：

* `output/ma7_scan_<YYYYMMDD>.csv`（`--all-state` 为 `ma7_scan_state_*`）
* `output/ma7_backtest_<时间戳>.xlsx / .txt`
* `output/charts/ma7_nav_<时间戳>.png`

回测的 `signal_date` 使用**确认日**（如 7/15、10/12），避免未来函数；
Excel 的 `MA7上抛信号` 表同时保留 `start_date`（7/14、10/9）。
