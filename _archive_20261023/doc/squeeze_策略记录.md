# SQUEEZE 策略记录（均线粘合 → 放量突破）

> 独立工具包 `squeeze/` 的决策日志。**按日期倒序**追加，最新在最上面。
> 与 `doc/coil_策略记录.md`（横盘蓄势状态机）、`doc/burst_策略记录.md`
> （爆发形态相似度）分离：本文件只记录 squeeze 的定义、参数、验证与复现。

## 0. 边界与目录

| 项 | 约定 |
|---|---|
| 代码 | `squeeze/{__init__,settings,rule}.py`、`squeeze_scan.py`、`squeeze_validate.py` |
| 参数 | `config/squeeze.json`（唯一来源；缺项回落 `squeeze/settings.py:DEF`） |
| 产物 | `output/squeeze/` |
| 依赖方向 | `squeeze → coil.features`（纯函数：滚动均值/MACD/位移）；`squeeze_validate → coil.evaluate`（事件研究工具）；数据层 `mlr.data / mlr.settings` |
| 禁止反向 | `mlr`、`coil`、`burst` 不引用 `squeeze`；`squeeze` 不读其它策略的 json |
| 删除影响 | 删除 `squeeze/` 与两个入口脚本，其余策略与产物不受影响 |

与两个既有包的定位差异：

* `coil`：**状态机**，必须先满足 120 日窗口内 cv/箱体/波动压缩/MACD 带宽等
  9 个统计量并连续蓄势 ≥60 根，突破时还要求 MACD 金叉 ≤5 根 + 红柱放大；
* `burst`：**连续评分**，不要求前期横盘，只度量最近 5 日像不像“标准爆发”；
* `squeeze`：只保留用户公式的**三件事**——均线粘合度、当日涨幅、放量，
  把 MACD 零轴 / MA120 走平 / 多头排列 / 振幅收缩做成可选开关。
  它比 `coil` 宽松（不要求箱体突破、不要求金叉新鲜），所以能抓到
  “粘合后横了 3 周才突破”的形态（见 §2 的 600188）。

## 1. 形态的数学定义

设 $C_t,H_t,L_t,V_t$ 为后复权收/高/低/量，$MA_k(t)=\frac1k\sum_{i=0}^{k-1}C_{t-i}$。
信号在 $T$ 日收盘后确认，$T+1$ 开盘可执行。

### 1.1 判定链

| 条件 | 定义 | 默认 |
|---|---|---|
| 粘合度 | $stick=(\max(MA_7,MA_{21},MA_{120})-\min(\cdot))/\min(\cdot)$ | $\le 5\%$ |
| 突破 | $C_T>\max(MA_7,MA_{21},MA_{120})$ 且 $C_T/C_{T-1}-1\ge 5\%$ | 开 |
| 放量 | $V_T>MA(V,5)$（含当日，通达信口径） | 开 |
| 零轴 | $DIF>DEA$ 且 $DIF/C_T\ge -0.5\%$ | 关 |
| 走平 | $\lvert MA_{120}(T)/MA_{120}(T-5)-1\rvert\le 1\%$ | 关 |
| 多头 | $MA_7>MA_{21}>MA_{120}$ | 关 |
| 振幅 | 近 60 日 $(\max H-\min L)/\min L\le 30\%$ | 关 |
| 冷却 | 同一股票 20 个交易日内只记一次 | 开 |

MACD 默认 `(30,89,9)`：参考图标称 `(30,90,9)`，用 89 替代 90，
与 `coil` 保持同一套参数。

### 1.1b 蓄势质量（v0.1.4，默认开，`--no-shape` 可关）

上面的判定只回答“均线现在是否靠得近”，回答不了**“是靠什么粘起来的”**。
一条从 110 跌到 78 再反弹 15% 的票，同样能让三条均线靠在一起，但图形上是
V 型反弹的第一波，不是横盘蓄势。补六条“过程”证据（全部只用 T 日及以前数据）：

| 条件 | 定义 | 默认 | 拦住的是 |
|---|---|---|---|
| 20 日振幅 | $(\max H-\min L)/\min L$，T−20..T−1 | ≤ 12% | 反弹通道、宽幅震荡 |
| 40 日振幅 | 同上，T−40..T−1 | ≤ 15% | 中期还在大波动 |
| 急拉 | 120 日内最大 5 日涨幅 | ≤ 12% | 冲高回落后的平台 |
| 急杀 | 120 日内最大 5 日跌幅 | ≥ −10% | 断头铡刀后的平台 |
| 离底 | $C_T/\min L_{T-120..T-1}-1$ | ≤ 20% | 刚从底部弹起来的第一波 |
| 长均线 | $MA_{120}\le MA_{21}(1+1\%)$ | 开 | 120 日线还在头顶压着 |

这六条是**形状证据**，不是收益因子：§4.7 显示它把信号从 4,020 砍到 445、
胜率升到 46.3%、中位数升到 −0.63%，但均值 alpha 从 +0.60% 降到 −0.15%
（右尾被砍掉）。它解决的是“像不像”，不是“赚不赚”。

### 1.2 对用户原始公式的三处修正

1. **`DIF > -0.5` 不可跨股票比较**。DIF 的单位是元：5 元股的 −0.5 是 −10%，
   100 元股的 −0.5 是 −0.5%。改为 $DIF/C \ge -0.5\%$（归一化），
   这样“在零轴附近”对所有价位含义一致。
2. **原公式的 `COND_E`（MACD）没有写进 `XG`**，等于从未生效。本实现把它做成
   显式开关 `use_macd`，默认关（与用户原式等价），并在验证里单独测一档。
3. **`粘合度` 用 `min` 做分母**，与 `coil` 用 `close` 做分母不同。前者对低价股
   更严格、对高价股更宽松；两者在 A 股 3~100 元区间差异 <1 个百分点，保留
   用户口径，但在 `coil` 里剔重时注意不是同一个阈值。

此外，用户 Python 伪代码里的 `if close > rolling(120).max()*0.8` 与注释
“排除已经涨上天的”**方向相反**（该条件对绝大多数股票恒真），本实现不采用，
改为可选的 `max_range` 前 60 日振幅约束。

### 1.3 排序分（0~100，只影响排序，不参与硬条件）

$$\mathrm{Score}=100\left(0.45\cdot\mathrm{clip}(1-\frac{stick}{stick_{max}},0,1)+0.30\cdot\mathrm{clip}(\frac{pct}{10\%},0,1)+0.25\cdot\mathrm{clip}(\frac{vol\_mult-1}{2},0,1)\right)$$

`vol_mult = V_T / mean(V_{T-20..T-1})`（不含当日）。粘合越紧、涨幅越足、量放得越大，
分越高；`score` 与 alpha 的关系见 §4，**不单调**，不要当概率用。

## 2. 参考形态核对（600188 兖矿能源）

图上读数：MA7 13.29 / MA21 13.01 / MA120 13.15，DIF 0.02 / DEA −0.01，
标注“2025 年 1 月”。**缓存数据不支持 2025-01**：

| 日期 | MA7 | MA21 | MA120 | 粘合度 | DIF | DEA |
|---|---|---|---|---|---|---|
| 2025-01-13 | 84.58 | 86.39 | 88.83 | 5.02% | −2.149 | −1.718 |
| 2025-01-16 | 83.95 | 85.74 | 88.65 | 5.59% | −2.332 | −1.996 |
| **2026-01-13** | **89.07** | **87.61** | **88.09** | **1.66%** | **+0.103** | **−0.020** |

2025-01 的粘合度是 5.0~5.6%、DIF 约为价格的 −2.5%，与截图（2.1%、+0.1%）
完全不同；**2026-01-13** 全部对上：按前复权系数 6.70 折算，
89.07/6.70 = **13.29**，88.09/6.70 = **13.15**，87.61/6.70 = 13.08（图上 13.01），
DIF 0.103/6.70 = **0.015**（图上 0.02），DEA −0.020/6.70 = **−0.003**（图上 −0.01）。
三条均线的相对位置（MA7 最高、MA21 最低、MA120 居中）也完全一致。
故参考日按 **2026-01-13** 登记（`config/squeeze.json:reference`）。

其后走势（`python squeeze_scan.py --case 600188 --case-date 2026-01-13`）：

* 2026-01-12 DIF 上穿 0 轴，01-13~01-30 粘合度 0.6%~2.1% 一路收紧，量能温和放大；
* **2026-02-04** 收 94.27（+6.10%），量比 2.17，粘合 2.32%，收盘站上三条均线
  且越过 120 日箱体上沿 93.83 → **squeeze 信号，score 57.0**；
* 之后 2026-02-11~03-06 从 99.66 涨到 109.91（区间最高 114.67），20 日 +17%。

对照：`coil_scan` 在同一区间 **0 条信号**——它要求“MACD 金叉 ≤5 根内突破”，
而本例金叉在 01-12、突破在 02-04（间隔 16 根），被 `fresh_days` 直接卡掉。
这说明 squeeze 不是 coil 的子集，两者是不同时间尺度的突破定义。


## 3. 扫描用法与样例

> 定位：**形态选股筛选器**，不是收益预测器。输出每只票的形态证据（粘合多紧、
> 持续多久、离箱体多远、量能多大），由人做最后取舍；§4 已证明这套形态本身
> 不构成可实盘的多头策略。

```bat
:: 默认（形态硬条件 ON）：最近 10 个交易日，全市场
python squeeze_scan.py --universe all --recent 10

:: 原式口径（只要求粘合+大涨+放量，不看粘了多久/箱体/MA120）
python squeeze_scan.py --universe all --recent 10 --literal

:: 实用清单：剔 ST / 剔当日涨停 / 价格>=2 元 / 成交额>=0.5 亿，只要 A/B 级
python squeeze_scan.py --universe all --recent 10 --clean --min-grade B

:: 观察池：已长期粘合、尚未突破（提前埋伏名单）
python squeeze_scan.py --universe all --watch --watch-min-days 20 --min-amount 1

:: 指定日 + 更宽阈值 + 要求多头排列
python squeeze_scan.py --date 2026-10-19 --max-stick 0.08 --stack

:: 复核参考形态
python squeeze_scan.py --case 600188 --case-date 2026-01-13
```

| 参数 | 默认 | 作用 |
|---|---|---|
| `--clean` | 关 | 预设：`--exclude-st --exclude-limit --min-price 2 --min-amount 0.5` |
| `--exclude-st` | 关 | 名称含 ST / *ST / “退” 的剔除 |
| `--exclude-limit` | 关 | T 日涨幅已达板（主板 9.5% / 创业板科创板 19.5% / 北交所 29.5%）剔除 |
| `--min-price` | 0 | 收盘价下限（元），过滤低价壳股 |
| `--min-amount` | 0 | 当日成交额下限（亿元），保证次日能进出 |
| `--min-grade` | 不限 | 只要 A 或 B 级（见 §3.2） |
| `--min-run` | 10 | 粘合天数下限（`0`=不限） |
| `--max-box-h` | 0.30 | 突破前 60 日箱体高度上限（`0`=不限） |
| `--no-box` | 关 | 不要求收盘站上箱体上沿 |
| `--box-tol` | 0.02 | 允许收盘低于箱体上沿 2% |
| `--ma120-min` | −0.005 | MA120 5 日变化下限（不走坏） |
| `--no-ma120-floor` | 关 | 取消 MA120 条件 |
| `--no-shape` | 关 | 关闭“蓄势质量”六条（退回 v0.1.3 口径） |
| `--shape-range20` | 0.12 | 突破前 20 日振幅上限（`0`=不限） |
| `--shape-spike5` | 0.12 | 120 日内最大 5 日涨幅上限（`0`=不限） |
| `--shape-off-low` | 0.20 | 收盘距 120 日低点上限 |
| `--shape-ma120-over` | 0.01 | MA120 允许高于 MA21 的幅度 |
| `--literal` | 关 | **关闭全部形态条件，退回原式**（§1.1） |
| `--watch` | 关 | 观察池模式（见 §3.3），输出 `squeeze_watch_<日期>.xlsx` |
| `--watch-band` | 0.03 | 观察池：收盘距均线束的上下限 |
| `--watch-min-days` | 10 | 观察池：粘合至少持续 N 个交易日 |

**形态硬条件**（默认 ON，`config/squeeze.json:rule`）只回答“图形像不像红框”：

1. `粘合天数 >= 10`：均线已经贴合足够久，不是刚碰上 1~3 天；
2. `箱体高度(近 60 日，不含当日) <= 30%`：突破前是窄幅横盘，不是宽幅震荡；
3. `收盘 >= 箱体上沿 × (1 − 2%)`：突破的是箱体，不只是三条均线；
4. `MA120 5 日变化 >= −0.5%`：长期均线没有明显走坏。

**蓄势质量**（v0.1.4 默认 ON，§1.1b）：20/40 日振幅 ≤12%/15%、120 日内无
5 日急拉 >12% 或急杀 <−10%、收盘距 120 日低点 ≤20%、MA120 ≤ MA21×(1+1%)。

形态硬条件是**信号的一部分**（默认 ON，`--literal` 可关闭）；下文的可执行性过滤
（价格/成交额/ST/涨停/等级）只作用于输出清单，不改变 `scan()` 的判定，被过滤的
信号也不占用 20 日冷却期，避免“涨停买不进 → 同票后面的机会也被吞掉”。

2026-09-29 ~ 2026-10-19（10 个交易日）全市场：

| 口径 | 信号数 | 说明 |
|---|---|---|
| `--literal` | 119 条 / 119 只 | 原式；含大量反弹、刚贴合 |
| `--no-shape`（v0.1.3 四条件） | 9 条 / 9 只 | 仍是“跌多了碰巧收敛”，见 §3.5 |
| **默认（四条件 + 蓄势）** | **1 条** | 只剩 300770 |
| 默认 + `--clean` | 1 条 | 300770（A 级） |

默认口径（1 条）：

| 代码 | 名称 | 信号日 | 涨幅% | 粘合度% | 粘合天数 | 距箱体% | 箱体高度% | 量比 | 等级 | score |
|---|---|---|---|---|---|---|---|---|---|---|
| 300770 | 新媒股份 | 2026-10-09 | 7.22 | 0.90 | 25 | −1.68 | 11.43 | 5.47 | A | 83.5 |

`--no-shape` 时的 9 条（v0.1.3 口径，仅作对照）：600329、600252、300299、600851、
002675、600621、600812、002262、300770 —— 除 300770 外全是“急跌后第一波反弹”，
逐只的失败指标见 §3.5。

默认口径的收益表现见 **§4.5 / §4.7**：四条件把 alpha 抬到 +0.60%（样本外 +0.06%），
再加蓄势后均值降到 −0.15%，但胜率升到 46.3%、中位升到 −0.63%——
**“图形更像”不等于“更能赚”**，清单仍需人来取舍。

### 3.1 输出列

`形态明细` 在原字段之外新增（全部由 T 日及以前数据算出）：

| 列 | 含义 |
|---|---|
| 现价 | `成交额/成交量`，真实成交均价（元）；`--min-price` 用它判断 |
| 粘合天数 | 截至 T 日连续满足 `stick <= max_stick` 的交易日数 |
| 突破幅度% | `C_T / max(MA7,MA21,MA120) - 1`，越大越像“真突破”而非贴线 |
| 距箱体% | `C_T / 箱体上沿 - 1`；箱体上沿 = 前 120 日最高价的 90 分位，负值=尚未过顶 |
| 箱体高度% | 突破前 60 日（不含当日）`(最高-最低)/最低`；越小说明横盘越窄 |
| 均线排列 | 多头（MA7>MA21>MA120）/ 空头 / 纠缠 |
| MA120趋势 | 近 5 日 MA120 变动 >+0.5% 记上行，<−0.5% 记下行，否则走平 |
| 20日振幅% | 突破前 20 日（不含当日）`(最高-最低)/最低`，蓄势段平不平 |
| 120日最大5日涨% | 120 日内最大 5 日涨幅，识别“冲高回落” |
| 离120日低% | 收盘距 120 日低点，识别“反弹第一波” |
| MA120-MA21% | 正数=长均线还在头顶压着（>1% 被蓄势条件拦下） |
| 成交额(亿) | T 日成交额，用于判断次日进出容量 |
| 是否涨停 | 收盘涨幅达板记 Y，一字板记“一字”（次日大概率买不进） |
| ST | 名称含 ST / *ST / “退” |
| 形态等级 | A/B/C，见 §3.2 |
| 信号价(次日开盘) | T+1 开盘价，仅作执行参考，不判断能否成交 |

`按日汇总` 仍按信号日统计；`口径说明` 记录当次使用的全部阈值与过滤开关。
代码列强制文本（保留 000860 前导零），所有 sheet 带自动筛选。
注意：`收盘`/`MA*`/`箱体上沿` 都是**后复权价**，只用于比例计算，不能当真实价位；
真实价位看 `现价`（600188 的 2026-10-19 后复权收盘 111.94，真实约 19.13 元）。

### 3.2 形态等级（A/B/C）

| 等级 | 条件（默认，`config/squeeze.json:grade`） |
|---|---|
| A | 粘合 ≤3% 且 粘合天数 ≥20 且 量比 ≥1.5 |
| B | 粘合 ≤5% 且 粘合天数 ≥10 且 量比 ≥1.2 |
| C | 通过形态硬条件，但未达到 B（粘合偏松 / 量能不足） |

可选更严：`a_need_box`（A 级须站上箱体上沿）、`a_need_stack`（A 级须多头排列）。
2026-10-19 窗口默认口径只剩 1 条，即 300770（A，粘合 0.90%、连续 25 日、量比 5.47）；
参考形态 600188 在 2026-02-04 也是 A（粘合 2.32%、连续 43 日、量比 2.17）。
**等级只表示形态完整度，不是上涨概率**，与 §4.3 的“越粘越好不单调”一起看。

### 3.3 观察池（`--watch`）

语义：**已经粘合、但还没突破**的票——用于提前跟踪，等它自己触发 §1.1 的信号。
与 `形态明细` 不重叠：观察池要求当日 `pct < min_pct`（没大涨），
形态清单要求 `pct >= min_pct` 且收盘站上均线束。

| 条件（默认） | 值 |
|---|---|
| 处于粘合 | `stick <= 5%` |
| 已持续 | `粘合天数 >= watch_min_days`（10） |
| 贴近均线束 | `|C/MA束 - 1| <= watch_band`（3%） |
| 尚未突破 | 当日涨幅 < 5% |
| 箱体不宽 | 前 60 日箱体高度 <= 30% |
| MA120 不走坏 | MA120 5 日变化 >= −0.5% |
| 蓄势质量 | 同 §1.1b 的六条（20/40 日振幅、无急拉急杀、离 120 日低点、MA120 不压顶） |

输出 `观察池` sheet：代码/名称/现价/收盘（后复权）/粘合度/粘合天数/距均线束%/量比/均线排列/
MA120趋势/箱体上沿/距箱体%/箱体高度%/20日振幅%/离120日低%/MA120-MA21%/成交额(亿)/ST，
按粘合天数降序。2026-10-19 默认参数下 **113 只**（v0.1.3 是 212 只，蓄势条件砍掉
约一半）——数量大是正常的，用 `--watch-min-days 20 --min-amount 1 --exclude-st`
或 Excel 自动筛选收缩到 73 只。
池子大不等于机会多：§4 的结论是突破后都难赚钱，观察池只解决“什么时候开始看”。

观察池不检查“站上箱体”（此时股价还在箱内），粘合天数由 `--watch-min-days`
单独控制，因此它能找到“红框当下”的票；而 `形态明细` 只列突破日。

### 3.4 为什么 000860 / 600698 被剔除

这两只在 2026-10-19 都满足原式（粘合 ≤5% + 涨幅 ≥5% + 放量），但图形上都不是

**观察池**，不是突破清单。`--watch` 的语义正是把这种“红框当下”的票列出来。

### 4.5 形态硬条件的增量：滤掉 82% 信号，但没有样本外 alpha

选股器形态口径首次进入验证，与逐行可比的 `literal 5%` 对照
（`变体样本内外` / `变体逐年` 两个 sheet）：

| 变体 | 样本内 2017~2022 | 样本外 2023~2026 | 全样本 |
|---|---|---|---|
| literal 5% | +0.21%（n=12,010） | +0.31%（n=9,913） | +0.25% |
| 形态四条件（v0.1.3） | **+1.18%**（n=1,859） | **+0.06%**（n=1,995） | +0.60% |
| 形态+蓄势（v0.1.4） | −0.07%（n=172） | −0.21%（n=266） | −0.15% |

逐年均值 alpha（%）：2019 四条件 +4.57 vs 原式 +0.63、2021 +4.75 vs +3.24，
但 2024 四条件 **−4.08** vs 原式 −1.42；蓄势档在 2024 更差（−7.23）。

* 全样本看四条件是“过滤有效”：信号 22,582 → 4,020（−82%），均值 +0.25% → +0.60%，
  按日聚合 t −3.52 → −0.13，胜率 42.8% → 44.2%，中位 −1.94% → −1.67%。
* 但**样本外只剩 +0.06%**（原式 +0.31%），增量几乎全部来自 2019/2021 两个普涨年：
  形态筛出的“长期横盘箱体”在小盘/题材牛市弹性更大，这是**风格暴露**，
  不是形态本身的稳定溢价。
* 中位仍为负、胜率不到 45%，**一半以上交易亏钱的结构没变**。

结论：形态条件的定位是**图形有效性过滤**（把 000860/600698 这类假形态挡在外面），
**不是 alpha 增强器**。把它宣传成“过滤后更能赚”会高估——样本外它甚至略弱于原式。

### 4.6 蓄势质量：胜率和中位数上去了，均值和右尾下来了

v0.1.4 的六条蓄势条件把 4,020 条压到 445 条（−89%），20 日口径：

| 口径 | n | 均值alpha | 中位alpha | 胜率% | 按日聚合t |
|---|---|---|---|---|---|
| literal 5% | 21,923 | +0.25% | −1.94% | 42.8 | −3.52 |
| 形态四条件（v0.1.3） | 3,854 | +0.60% | −1.67% | 44.2 | −0.13 |
| 形态+蓄势（v0.1.4） | 438 | **−0.15%** | **−0.63%** | **46.3** | −0.59 |

* 胜率 44.2% → **46.3%**、中位 −1.67% → **−0.63%**：单笔“更像红框”的票确实更少亏；
* 均值 +0.60% → **−0.15%**：因为右尾被砍掉了——大赢家几乎都来自那些“V 型反弹后
  一路走强”的票，而蓄势条件正好把它们排除；
* 样本外 −0.21%（n=266），胜率 49.6%，**绝对收益依旧接近 0**。

一句话：**蓄势条件是“图形纯度”过滤器，用均值换中位数**。这也是为什么它适合当
选股清单（人工只看 1~2 只），不适合当收益策略。

### 4.7 结论：不构成可实盘多头策略

* **有增量信息**：相对“不看粘合的纯放量大涨”（−0.18%），粘合过滤把均值抬到
  +0.25%（+0.43pp），按日聚合 t 从 −8.08 收敛到 −3.52；按日 t 为正的只有
  “严格组合”（+0.47）一档，属于**收紧样本后方差变大**的结果，不能单独当证据。
* **绝对收益不够**：均值 +0.25% 扣成本后 ≈ 0，中位数 −1.94%、胜率 42.8%，
  六成以上交易亏钱，靠右尾扛均值。叠加蓄势后中位改善，但均值转负——两条路都
  到不了可实盘的门槛。
* **按日聚合 t 为负**说明收益集中在少数“全市场大涨日”：这类日子信号成批出现，
  收益好；股票个体事件日反而负。实盘无法预知哪天是普涨日，等于把仓位押在
  市场 Beta 上，而不是形态上。
* 与 `burst` 的结论一致（burst 全维度负 alpha）；与 `coil` 的“v0.1.0 不构成
  可实盘策略”一致。三个包从不同角度切同一现象，得到同一个答案：
  **A 股“放量大涨首日”的可交易 alpha 已基本被消耗掉。**

## 6. 已知问题

1. **涨停/一字板默认不剔除**：T 日涨停 + T+1 一字开盘的信号仍会出现在清单里（表内
   `是否涨停` 列有标记）；需要干净清单时加 `--exclude-limit` / `--clean`。即使 T 日
   未涨停，`信号价(次日开盘)` 也只是开盘价，不保证能成交。
2. **`score` 与 alpha 不单调**（评分数位表），高分不等于高胜率；当前只能排序展示。
3. **按日聚合 t 为负**是结构性问题（信号成批出现在普涨日），不是样本量不足，
   加大样本不会改善；要改成“同日横截面多空”或加择时条件才有意义。
4. **粘合度分母用 `min(MA)`**：低价股阈值偏严、高价股偏松；与 `coil` 的
   `max|MA差|/close` 口径不能直接互换阈值。
5. **无市值/次新过滤**：可执行性只有价格、成交额、ST、涨停四项；市值、上市天数、
   停牌复牌未处理，次新股靠 `min_bars` 隐式排除。
6. **参考日与用户口述差一年**：缓存证据指向 2026-01-13，需用户确认截图日期；
   若确为 2025-01，则参考对象不是 600188 这段行情（见 §2）。
7. **未与 `coil` 做交集/并集回测**：两者时间尺度不同（squeeze 允许金叉后 3 周才突破），
   交集的交易频率与 alpha 值得单独测。
8. **MACD 参数用 89 而非图上标的 90**，日线上差异可忽略，复现图上数值时有
   0.2% 级偏差。
9. **原式 ≠ 图形形态**：三条均线当日靠得近，可能只是下跌后的反弹或刚贴合；
   `--literal` 会把这些都列出来（119 条 → v0.1.3 四条件 9 条 → v0.1.4 蓄势后 1 条）。
   默认口径已排除，但 `--literal` 仅用于对照历史验证，不建议当选股清单。
10. **箱体上沿用 120 日最高价的 90 分位**，不是“最近一段横盘的高点”；对刚创
    新高后回踩的票会偏保守。形态判定允许低于上沿 2%（`--box-tol`）。
11. **形态硬条件没有样本外 alpha**：全样本 +0.60% 主要来自 2019/2021 两个普涨年，
    样本外 +0.06% 反而略低于原式的 +0.31%（§4.5）。它解决的是“图形像不像红框”，
    不是“买了能不能赚”；不要把它当选股优势来宣传。
12. **蓄势阈值的正例只有 2 个**（300770、600188），六条阈值是“让这两个都通过、
    其余 8 只都卡住”定的，属于**图形定义**而非统计估计。它把均值 alpha 从 +0.60%
    降到 −0.15%（§4.6）：胜率/中位数变好、右尾被砍。002675（MA120 高 1.2%）、
    600621（离底 21.6%）属于阈值附近“擦线被拦”的票，放宽
    `--shape-ma120-over` / `--shape-off-low` 会回来，这是已知的模糊地带。
