# LAUNCH 策略记录（平台整理 → 放量上抛）

> 独立工具 `launch_scan.py` / `launch_validate.py` 的决策日志。日线口径。
> 与 `squeeze`（长期均线粘合后的底部突破）、`coil`（120 日蓄势状态机）、
> `burst`（爆发相似度）分离：launch 只做**“平台 → 上抛”**这一种结构。

## 0. 形态定义

用户给的样例是 000400 许继电气（周线）上的两个红框：一段窄幅横盘之后，价格
放量拉出主升。翻译成日线，T 日收盘可确认的全部条件：

| 条件 | 定义 | 默认 |
|---|---|---|
| 平台 | 近 `box_win` 日（不含 T）振幅 `(maxH−minL)/minL` | ≤ 12%，20 日 |
| 突破 | `C_T ≥ 平台高点×(1−tol)` 且涨幅 ≥ 4% 且量比（/前 5 日均量）≥ 1.5 | tol 0.5% |
| 趋势 | MA120 的 20 日变化 ≥ −0.5%、60 日变化 ≥ +3%，且 `C_T ≥ MA120×0.97` | 开 |
| 位置 | `C_T ≥ 250 日最高价×0.60`（不在深坑里） | 0.60 |
| MACD | `DIF>DEA` 且 `DIF/C ≥ −5%`，且 20 日内（平台期内）出现过金叉 | (12,26,9) |
| 冷却 | 同一股票 20 个交易日内只记一次 | 20 |

信号日 = 平台被放量突破的那一天，T+1 开盘可执行；没有未来函数。

## 1. 与 squeeze 的区别

| | squeeze | launch |
|---|---|---|
| 前期形态 | 长期均线粘合（MA7/21/120 靠拢），底部横盘 | 已有波动/趋势，**近 20 日**窄幅平台 |
| 触发 | 收盘站上三条均线 + 站上 120 日箱体上沿 | 收盘站上 **20 日平台高点** |
| 时间尺度 | 月级（粘合 25~60 日） | 周级（平台 15~30 日） |
| 典型 | 300770（横 25 天后放量） | 000400 的两次主升起点 |

两者可以叠加：先 `launch_scan` 出“正在突破”的票，再用 `squeeze_scan --case`
看它的均线结构；或反过来在 `squeeze` 观察池里等 `launch` 触发。

## 2. 用法

```bat
:: 最近 10 个交易日
python launch_scan.py --recent 10

:: 只看今天 / 指定日
python launch_scan.py --date 2026-10-19

:: 更严：平台更窄、必须已金叉、离前高更近
python launch_scan.py --recent 10 --box-max-h 0.09 --pos250-min 0.8

:: 放宽：3% 涨幅也算突破
python launch_scan.py --recent 10 --min-pct 0.03

:: 观察池：平台中、尚未突破（提前埋伏）
python launch_scan.py --watch

:: 复核单只
python launch_scan.py --case 000400 --case-date 2024-04-11

:: 统计验证（约 1 分钟）
python launch_validate.py
```

参数（`config/launch.json` 可改默认）：`--box-win --box-max-h --min-pct
--min-vol --pos250-min --ma120-60min --cross-win --no-cross --min-price
--min-amount --exclude-st --exclude-limit`。

## 3. 输出列

`形态明细`：代码 / 名称 / 信号日 / 收盘(后复权) / 现价(成交额÷成交量) / 涨幅% /
量比 / 平台振幅% / 平台高点 / 突破幅度% / 平台位置% / MA7 / MA21 / MA120 /
MA120斜率%(20日) / MA120_60日% / 距250高% / DIF / DEA / DIF/C% / 成交额(亿) /
是否涨停 / ST / score / 信号价(次日开盘)。

`观察池`（`--watch`）：平台中、尚未突破的票，多一列 `金叉20日内`。

`口径说明`：当次全部阈值与开关。

## 5. 统计验证（2017-01-01 ~ 2026-10-19，全市场）

4,568 条信号（含 20 日冷却），事件研究口径同 `coil.evaluate`：T+1 开盘买入、
h 日后开盘卖出、扣双边 0.2%、减沪深300：

| 持有期 | n | 均值alpha | 中位alpha | 胜率% | 逐笔t | 按日聚合t |
|---|---|---|---|---|---|---|
| 5 | 4,495 | −0.05% | −0.70% | 44.5 | −0.43 | −1.69 |
| 10 | 4,491 | +0.16% | −1.01% | 44.2 | 1.10 | −0.58 |
| **20** | 4,496 | +0.72% | −1.44% | 44.2 | 3.21 | **+1.98** |
| **40** | 4,479 | **+1.48%** | −1.77% | 43.7 | 4.83 | **+3.49** |

样本内外（20 日）：样本内 +0.24%（n=1,821）、样本外 **+1.04%**（n=2,675，胜率 45.2%），
样本外反而更好。逐年 20 日：2017 −0.81、2018 −2.51、2019 −0.66、2020 −0.20、
2021 +4.59、2022 −0.62、2023 +1.91、2024 −3.13、2025 +1.13、2026 +2.33。

**结论**：5/10 日接近 0（不再像早期版本那样明显亏在追高），20 日 +0.72%、
40 日 **+1.48%** 且按日聚合 t=**3.49**——是三个包里唯一在 40 日上 t 值超过 3 的
形态。但中位 −1.44%、胜率 43.7%，收益仍然靠右尾：它是“筛出正在上抛的票”的
工具，不是“买入即赚”的策略。

## 6. 已知问题

1. **平台长度固定 20 日**：用户截图里的横盘在周线上看有 8~12 周（日线 40~60 日），
   20 日只覆盖“最后一小段”。要更接近截图，用 `--box-win 40`。
2. **MACD 用日线 (12,26,9)**：截图的 MACD 是周线 (30,89,9)。日线上 30/89 太慢，
   金叉会滞后一个月以上，所以默认用标准参数；`config/launch.json` 可改回 (30,89,9)。
   金叉窗口是“20 日内（平台期内）金叉”，因为图上的金叉发生在**箱体内部**，
   突破往往在其后 1~4 周——用 5 日窗口会漏掉 000400 的 2026-01-13。
3. **趋势门槛 `ma120_60min=3%` 是按 000400 的 4 次信号定的**：2023-02-14 那次
   MA120 60 日只涨 2.2%（长期趋势还是平的），突破后 20 日 −8.1%，被用户判为
   “不算”；三次真信号分别是 17.7% / 6.0% / 10.9%。门槛落在 2.2% 与 6.0% 之间，
   属于**图形定义**而非统计估计，样本外可能还有别的“该算但被拦”的票。
4. **平台位置允许 >100%**：突破日收盘已越过平台高点，`平台位置%` 会大于 100。
5. **不区分一字板/涨停**：默认 `--exclude-limit` 开，但阈值是“涨幅 ≥9.0%（主板）”
   的近似，会把 +9.0~9.9% 未封板的票也剔除（同 squeeze）。
6. **信号集中在上升市**：2026 年 6~9 月每月只有 3~5 条（多数个股 MA120 转头向下），
   这是形态本身的性质；想要更多票，可把 `--ma120-60min` 降到 0.02。
7. **未与 squeeze/coil 做交集**：两者结构不同，交集的频率与 alpha 值得单独测。
