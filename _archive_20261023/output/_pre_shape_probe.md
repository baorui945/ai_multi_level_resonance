# 「金叉前段」模板扫描 · 数据验证（2026）

模板 601898（中煤能源）2025-11-11 ~ 2026-03-16，82 根，区间内 2 个金叉：
2026-01-30（第 57 根，小金叉）、**2026-02-05（第 61 根，主金叉）**。
→ 前段 = 2025-11-11 ~ 2026-02-05（**61 根**），后段 = 21 根。

## 1. 只用前段（61 根）在金叉当日做形状匹配

2026 年金叉当日样本 13,825 个（9,219 个 score>0）：

| 口径 | 数值 |
|---|---|
| 前段 score 中位数 | 0.8716 |
| 前段 score 99% / 99.9% 分位 | 0.9924 / 0.9967 |
| 前段 score 区分 18 笔的 AUC | **0.909** |
| 18 笔的前段 score 区间 | 0.908 ~ 1.000（中位分位 ~86%） |
| 阈值 0.98 | 756 个信号 / 702 只，覆盖 **9/18** |
| 阈值 0.99 | 196 个信号 / 192 只，覆盖 **1/18** |
| 阈值 0.995 | 31 个信号 / 31 只，覆盖 **1/18** |

**结论**：前段形状在“下跌→金叉”这种共性形态上高度同质，分布挤在 0.95~1.0，
AUC 0.909 只说明“目标股偏高于中位”，**不足以做阈值筛选**：放到 0.98 仍有 700 只，
提到 0.99 就把 17/18 目标筛掉。
