# 模板「整段」vs「金叉前段」——2026 回测对拍

日期：2026-10-20　标的模板：601898 中煤能源 2025-11-11 ~ 2026-03-16（MACD 30/89/9）

## 1. 改动（backtest_shrink.py）

| 新增参数 | 作用 |
|---|---|
| `--template-part {full,pre}` | `pre` = 模板只取「区间起点 → 区间内最后一个金叉日」，去掉金叉后上抛段 |
| `--pre-cross {last,first}` | 用区间内最后一个（默认，与 cross 买点一致）还是第一个金叉切分 |
| `--dump-matches OUT.csv` | 把匹配窗口清单（start/end/score/buy_date/bars_since_cross）落盘，供两种模板对拍 |

`pre` 下 L=61（金叉在第 61 根），模板里没有金叉后的上抛段 → 只有窗口终点贴近金叉日才可能高分，
`--entry-mode cross` 的买点（窗口内最后一个金叉日收盘）就落回金叉当日，不再依赖未来走势。
默认产物名自动带 `_pre` 标记。

## 3. 个股是否一致

- **候选事件层面**：整段 62 个事件 / 62 只；前段 0.98 有 2,510 个事件 / **2,035 只**（占全市场 3,307 只的 62%）。
  事件交集 **47/62**（整段的 76% 覆盖），但前段多出 2,463 个事件，精确率仅 **1.87%**。
- **个股集合**：交集 58/62，仅整段 4 只（002357/002486/300891/600246 等），仅前段 1,977 只 → 前段几乎是全市场。
- **实际成交（K=5 槽位）**：整段 21 笔 vs 前段 45 笔，**只有 1 笔买入日+股票完全相同**。
  槽位被前段海量候选占满，选出来的是另一批股票（前段成交里 000014/000021/000050/000333… 全是整段没选的）。
- **收紧阈值也救不回来**：0.99 → 覆盖整段 22/62（精确率 2.29%）；0.995 → 只剩 4/62。
  也就是说“前段高分”和“整段高分”几乎是两个互不相交的集合，靠提阈值只会把整段那 62 个一起筛掉。

## 4. 结论

1. 去掉金叉后上抛段的匹配判断后，模板退化为“任何刚出现 MACD 金叉的票”，阈值 0.98 只能筛掉 38% 的股票，
   完全没有选股力；2026 收益由 +124% 变成 −36%（纯口径 −16%，也只与基准持平略差）。
2. 整段模板的区分度几乎全部来自 **金叉后 21 根上抛段**（滞后中位 23 根、确认比金叉买入价高 21%），
   这部分恰恰是“事后信息”——所以整段口径的回测收益不能直接当实盘预期。
3. 想要“可实盘 + 有选股力”，只能从结构特征另建判据（缩量、DIF<DEA 占比、跌幅/位置、板块），
   而不是只截前半段形状。前段形状可保留作**必要条件**（挡掉高位/放量票），做主判据无效。
